# Maximus: Fitness Coach für Home Assistant

Trainings-App als Home-Assistant-Add-on: Routinen, Live-Training mit Satz-Tracking und Pausentimer, Verlauf, Fortschritt und Rekorde, Muskelerholung, Körpermaße und 3D-Übungsansichten.

## Installation
1. Home Assistant: Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories
2. `https://github.com/kevinluca1-ctrl/Maximus` hinzufügen
3. "Fitness Coach" installieren und starten. Die App erscheint als "Fitness" in der Seitenleiste.
